# ゲームルール

## 勝敗条件

- **敗北** — ライフが0になったら
- **勝利** — 60秒間に出てきたモンスターを全て倒したら

## ライフ

ライフ制。

- 到達で残機を1つ失い、到達したモンスターは消える
- ライフは3つ

## モンスターの出現

- 出現間隔: 3秒
- 同時に存在できる上限: 5体
- 出現位置: 出現箇所からランダム
- 出現するのは開始から60秒まで。以降は出さず、残りを倒し切ったらクリア

## 進行（ウェーブ）

[初版のスコープ外](./open-questions.md#初版のスコープ外)。難易度パラメーターの置き場所は[スコアと難易度](./scoring.md)に定める。

## 出題される単語の重複

初版は重複を避けない。同じ単語が同時に出たときにどれを倒すかは[タイピング入力と判定](./typing.md)で定める。
重複回避と再出題の扱いは[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 撃破と得点

- 画面下部の入力欄に英単語をタイプし、Enterで確定して正誤を判定する
  - 画面上に該当する単語があれば、そのモンスターに魔法が飛んで撃破
  - 該当する単語がなければ`×`が表示される
- 撃破時の得点計算は[スコアと難易度](./scoring.md)を参照。
