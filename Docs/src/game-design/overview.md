# ゲーム概要

## 何をするゲームか

魔法使いを操作し、押し寄せるモンスターの頭上に出た日本語を見て、対応する英単語をタイプする。打ち切ると魔法が飛んでモンスターを倒す。撃破が追いつかず魔法使いまで到達されたら終了。

## プラットフォームと操作

| | 内容 |
| :--- | :--- |
| プラットフォーム | Windows |
| 入力 | 物理キーボードによる英字タイプ |
| 画面向き | 全画面（1920x1080） |
| 描画 | 3D |

入力の実装は[入力](../unity-guidelines/input.md)にしたがう。
ビルドターゲットの切り替えは[残っている作業](./open-questions.md#残っている作業)を参照。

## 1プレイの流れ

1. タイトル画面、Enterキーでスタート
2. モンスターが画面奥から出現し、魔法使いへ向かって進む
3. 頭上の日本語に対応する英単語をタイプする。打ち切ると魔法が飛んでモンスターを倒す
4. いずれかのモンスターが魔法使いに到達したらライフを失い、0になったらゲームオーバー
5. リザルト画面でスコア・正確率・撃破数を表示する

## 想定プレイ時間

- 1プレイ: 60秒 or 死ぬまで
