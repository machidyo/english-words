# 間違えた単語の復習

リザルトのあとに、取りこぼした単語を出し直して打ち直させる。**学習としての中心はここにある。**

## 入り方と出方

- リザルトのランキング画面でEnterを押すと復習が始まる。取りこぼしが1つもなければ復習はなく、Enterはそのままもう一度遊ぶ操作になる
- 始めるときに、リザルトを引っ込めて残っているモンスターを消す。**1体ずつ向き合わせるため**
- 3語を終えたらランキング画面を出し直す。そこからのEnterはもう一度遊ぶ操作
- 復習中に魔法使いまで到達されてもライフは減らない。勝敗はもう決まっている

## 出題する単語

- 取りこぼした回数の多い順に3語。同数なら先に取りこぼしたものから出す
- 数えるのは**取りこぼした単語だけ**で、打ち間違いは数えない。打ち間違いはどの単語を狙っていたか決められない
- 数えるのは1プレイのぶんだけ。プレイをまたいで貯めることは[初版のスコープ外](./open-questions.md#初版のスコープ外)

## 1語の流れ

**見て打つ → 思い出して打つ → なにも見ずに打つ**と、手がかりを1段ずつ外す。

| 段階 | 入力欄に出るもの | 打ち切ったとき |
| :--- | :--- | :--- |
| お手本 | 答えを薄く出す | ノックバックして思い出しへ |
| 思い出し | なにも出さない。詰まるとヒント | ノックバックして仕上げへ。ヒントが出る前に打ち切れたらそのまま撃破 |
| 仕上げ | なにも出さない | 撃破 |

- モンスターは1体ずつ出す。出たては前進せず、**最初の打鍵で歩き出す。** 答えを読む時間を取るため
- 歩く速さはインゲームの半分
- **ヒントを見ずに思い出せたなら仕上げは省く。** 覚えている単語に3回打たせても得るものがない
- 打ち切るたびにノックバックさせて手応えを返す（[モンスター](./monster.md#ノックバック)）。倒すのは最後の1回だけ

## ヒント

思い出しの段階にだけ出る。

- 正しい入力が5秒進まなかったら、打ちかけを捨てて1文字目を薄く出す
- そのあとは3秒ごとに1文字ずつ増やす

## ギブアップ

仕上げでどうしても出てこないときの逃げ道。画面のボタンかEscで押せる。**打鍵中に手を離さずに押せるよう、キーからも受ける。**

- 押すとすぐ魔法が飛び、答えを3秒見せてから次の単語へ進む
- 出すのは仕上げの段階だけ。お手本と思い出しは待てば答えが出るので、詰まったままにならない

## 入力の扱い

- 打ち間違いはミスとして数えない。**復習は覚え直す場なので、記録も減点もしない。** 綴りが食い違った文字を赤く出してBackspaceで直させるところはインゲームと同じ（[タイピング入力と判定](./typing.md)）
- **復習の撃破は得点にしない。** 終わったリザルトの数字が動くと、何点取ったのかが分からなくなる
