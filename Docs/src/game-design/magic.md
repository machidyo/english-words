# 魔法の発射と着弾

英単語を打ち切ると魔法使いから魔法が飛び、モンスターに当たって倒す。**入力と撃破の間に「飛翔時間」が挟まる点がこのゲーム固有の設計上の要になる。**

## 撃破が成立するタイミング

入力完了で確定。打ち切った時点で撃破が確定し、魔法は演出として飛ぶ。

確定と同時にそのモンスターは入力対象と当たり判定から外れる（[モンスター](./monster.md)）。

## 魔法の種類

1種類。複数にする場合の軸は[初版のスコープ外](./open-questions.md#初版のスコープ外)に残している。

## 発射

- 発射位置: 魔法使いの杖の先
- 発射から着弾までの表現: 誘導
- 飛翔時間: 1秒
- 同時に複数の魔法が飛んでいる状態を許す

## 着弾

- 着弾時のモンスターの反応: [モンスター](./monster.md)の「撃破」を参照
- 着弾の演出とSE: [演出とサウンド](./audio-visual.md)を参照
- 対象が着弾前に消滅した場合: 魔法も消す。不発の演出は出さない
