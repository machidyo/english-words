# モンスター

## 状態遷移

```text
出現 → 接近中 → （撃破）→ 被弾 → 消滅
                └（到達）→ 魔法使いへ接触
```

- 接近中のモンスターだけがタイプの対象になる。
- 被弾中は当たり判定と入力対象から外す。移動は続けるので、魔法は誘導で追いかける。

**状態遷移をインスペクターのシリアライズ値に散らさない。** 理由と方針は[ドキュメントの書き方](../documentation.md)の「ドキュメントで補う前に、コードで辿れるようにできないか考える」にしたがう。

## 出現

- 出現位置: 画面上部から
- 出現間隔と同時出現数: [ゲームルール](./game-rules.md)を参照
- 出現時に単語を1つ割り当てる。割り当ての規則は[英単語データ](./word-data.md)を参照。

## 移動

- 移動速度: 出現位置から魔法使いまで5秒で到達する速さ。出現位置によらず所要時間を揃える
- 経路: 直線

速度の個体差は[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 頭上の表示

- 表示するもの: 日本語。**訳が複数あっても先頭のひとつだけ出す。** 頭上のラベルは短くないと読めない
- 表示の追従方法: ワールド空間のCanvas

タイプ済み文字の可視化と、表示が重なったときの読みやすさは[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 撃破

- 撃破の成立条件: 割り当てられた英単語をタイプし切ってEnterを押すこと。**確定は入力完了時**で、魔法は演出として飛ぶ（[魔法の発射と着弾](./magic.md)）
- 被弾から消滅までの演出とSE: [演出とサウンド](./audio-visual.md)を参照
- 撃破時の得点: [スコアと難易度](./scoring.md)を参照

## バリエーション

[初版のスコープ外](./open-questions.md#初版のスコープ外)。増やす場合の軸もそこに残している。
