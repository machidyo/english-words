# タイピング入力と判定

**このゲームの手触りを決める中心の仕様。** ここが決まらないと[英単語データ](./word-data.md)の表記ルールも決まらない。

## ターゲットの選び方

**全体一致。** 入力欄に打った文字列をEnterで確定し、画面上のモンスターの単語と突き合わせる。

- Enterで確定するので、先頭文字で対象をロックする仕組みは持たない
- 同じ単語のモンスターが同時に出ていてもよい。**その場合は魔法使いにもっとも近い個体を倒す。** 放っておくと先に到達するのがその個体だから
- 被弾中のモンスターは対象から外れる（[モンスター](./monster.md)）

## 入力の受け付け

- 受け付ける文字: `a`〜`z`のみ
- 大文字・小文字は区別しない
- Backspaceで末尾を1文字消す
- Enterで確定する。入力欄は確定と同時に空になる
- IME: **英字入力のみを前提とし、日本語入力がONのときの挙動は初版はなにもしない**

## ミスの扱い

該当する単語がなければミスとして記録し、入力は捨てる。ペナルティは課さない。

- ミスは正確率と最高連続撃破の計算に使う。[スコアと難易度](./scoring.md)を参照
- 初版ではペナルティを課さない

## フィードバック

入力が通ったこと・外れたことを即座に返す。詳細は[演出とサウンド](./audio-visual.md)。

- ミス時の表示: 赤い`×`を短時間出す。**絵文字の`❌`は日本語フォントに含まれず豆腐になるため使わない**

打鍵ごとのフィードバックと、一致した文字の色分けは[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 実装上の方針

- キー入力はイベントで受ける。毎フレームのポーリングでは取りこぼしが出る
- 入力の受け手はモンスター側に散らさず、**入力を解釈する箇所を1つに集める。** どのモンスターに当てるかを決める権限を集約し、反応（演出・撃破・得点）は各コンポーネントが購読する

物理キーボードでの打鍵確認は[残っている作業](./open-questions.md#残っている作業)。
