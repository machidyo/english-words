# スコアと難易度

## スコア計算

- 撃破1体あたりの基礎点: 100

単語の長さ・難易度による係数、ノーミスボーナス、コンボ倍率、遠くで倒したときのボーナスは[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 記録する指標

学習の振り返りに使うため、スコア以外も残す。

| 指標 | 定義 |
| :--- | :--- |
| 撃破数 | 倒したモンスターの数 |
| 正確率 | 撃破数 ÷ Enterで確定した回数 |
| 最高連続撃破 | ミスを挟まずに撃破し続けた最大数 |
| 間違えた入力 | 該当する単語がなかった入力の一覧 |

**「間違えた単語」ではなく「間違えた入力」を残している。** 全体一致でEnter確定にしたため対象がロックされず、プレイヤーがどの単語を間違えたのかは確定できない。復習機能を作るなら記録の仕方から見直す（[決まっていないこと](./open-questions.md#決まっていないこと)）。

リザルト画面に出すのは撃破数・正確率・最高連続撃破まで（[画面とUI](./screens.md)）。
