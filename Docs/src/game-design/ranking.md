# スコアの保存とランキング

プレイの記録を残し、リザルトのランキング画面で項目ごとのTop5を出す。

表示は[画面とUI](./screens.md#ランキング画面)を参照。

## スコアの保存

- 1プレイの結果を記録する。ゲームオーバーも記録する
- ゲーム終了（クリア、ゲームオーバー）時、結果表示の前に記録する
- 保存先
- - PersistentDataFoloder/scores/
- ファイル名
- - score\_yyyyMMdd.csv
- 保存するデータ
- - 日時
  - スコア
  - 撃破数
  - 正確率
  - 最高連続撃破数

## ランキング

- socres配下に存在する全てscoreファイルを読み込んで、上から5件ずつ取り出す
- - パフォーマンス問題も気になるところではあるが、当面はこれでいく
