# 英単語データ

## データが持つ情報

| 項目 | 型 | 用途 |
| :--- | :--- | :--- |
| 英単語 | string | タイプ対象の正解文字列 |
| 日本語 | string[] | モンスターの頭上に表示する語。複数の訳を持てる |
| 難易度 | int | 出題の絞り込み |
| カテゴリー | string | 単元・レベル別の出題 |

難易度とカテゴリーはデータとして持つだけで、初版では出題の絞り込みに使わない。

## 置き場所と形式

CSVを`Resources/Words/`に配置する。スプレッドシートのタブごとに1ファイルで、ゲームはフォルダー内のCSVをすべて出題範囲にする。

- 1行目は見出し
- 日本語は複数あるので、`"`で囲んでその中を`,`区切りとする

```csv
english,japanese,difficulty,category
cat,"ねこ,ネコ",1,animal
```

頭上に出すのは先頭のひとつだけ。詳細は[モンスター](./monster.md)の「頭上の表示」。

## 出題の選び方

ランダムに1つ選ぶ。

難易度で絞る・出題済みを避ける・同時出現中の単語との重複を避けるのは[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 表記の正規化

正解判定で揺れる要素を先に潰す。

- 大文字・小文字は無視する

空白・ハイフンを含む語や、複数の正解を持つ語は[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## データの入手と管理

Googleスプレッドシートで管理し、エディターのメニューからCSVに取り込む。手順はREADMEの「出題データ」にある。

- **取り込みはエディターで行い、実行時には取りにいかない。** CSVはビルドに含まれ、オフラインでも動く。単語の変更がgitの差分に残る
- シートは「リンクを知っている全員が閲覧可」にし、認証なしでCSVとして書き出す
- タブを単語セットの単位にする。タイトルでの単語セットの選択は[初版のスコープ外](./open-questions.md#初版のスコープ外)なので、今はすべてのタブから出題する
- **全タブを検証し終えてから書き出し、1つでも失敗したら何も書き換えない。** 実行時のパーサーは不正な行を黙って飛ばすため、取り込みの時点で止める
- 書き出すCSVの書式は、手で作っていたときに揃える（日本語は訳が1つでも`"`で囲む）
- 同じ単語が複数のタブにあっても止めない。出題されやすくなるので警告だけ出す
