# 魔法使いと防衛ライン

## 魔法使いの位置づけ

プレイヤーが操作する主人公。タイプした英単語が魔法になって飛ぶ。魔法そのものの仕様は[魔法の発射と着弾](./magic.md)に置く。

- 移動しない
- 向きを変えない
- 見た目: `Synty/PolygonDungeon/Prefabs/Characters/SM_Chr_Tormented_Soul_01`。**仮なので差し替えられるようにしておく**（[残っている作業](./open-questions.md#残っている作業)）

## 用語

**「プレイヤー」と「魔法使い」を書き分ける。** 混ぜると、UIの記述で誰の話かが読み取れなくなる。

| 語 | 指すもの |
| :--- | :--- |
| プレイヤー | 操作している人 |
| 魔法使い | 画面上の主人公キャラクター |

## 防衛ライン

- 位置: 魔法使い自身
- 見せ方: 魔法使い自身
- モンスターが到達したときの判定方法: コリジョン

## 敗北の判定

- 成立条件: [ゲームルール](./game-rules.md)を参照
- 到達したモンスターは消え、ライフが1つ減る
- 到達から[リザルト画面](./screens.md)へ遷移するまでの演出: [演出とサウンド](./audio-visual.md)を参照
