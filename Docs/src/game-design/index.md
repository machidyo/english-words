# ゲーム設計（English Words）

英単語をタイピングして覚えるゲームの仕様書。**このプロジェクト固有の設計であり、他の章のような全社ガイドラインではない。**

## コンセプト

主人公は魔法使い。モンスターの頭上に表示された日本語に対応する英単語をタイプすると魔法が飛び、モンスターを倒す。魔法使いまで近寄られたら負け。

1. モンスターが出現し、頭上に日本語が表示される
2. 対になる英単語をタイプすると魔法が飛んでモンスターを倒す
3. 魔法使いまで近寄られたら負け

## 書くときの方針

- **決まっていないこと・作らないと決めたこと・残っている作業は[未決事項](./open-questions.md)に集める。** 各節では列挙せず、そこへリンクする。決まったら該当の節に本文として書き、未決事項からは消す。
- 各節には**決まっていることだけ**を断定で書く。
- コードを読めばわかることは書かない。判断基準は[ドキュメントの書き方](../documentation.md)にしたがう。
- 実装を変えたら同じタイミングで該当箇所を直す。直せない記述は消す。
