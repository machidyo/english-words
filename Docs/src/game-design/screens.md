# 画面とUI

## 画面構成

| 画面 | 役割 | 遷移先 |
| :--- | :--- | :--- |
| タイトル | 開始 | インゲーム |
| インゲーム | ゲーム本体 | リザルト |
| リザルト | スコア表示、復習、リトライ、タイトルへ戻る | 復習 / タイトル / インゲーム |
| 復習 | 取りこぼした単語の打ち直し | リザルト |

シーンはタイトル用とインゲーム用の2つに分ける。分け方と遷移は[実装構成](./architecture.md)を参照。

**入口となるシーンはREADMEに書く。**

## インゲームのHUD

表示する要素を確定させる。増やしすぎるとタイプ中に読めない。

- 画面上部
  - スコア
  - ライフ
  - 経過時間
- 画面下部
  - 現在の入力中の文字列

## タイトル画面

Enterで開始する。

単語セット・難易度の選択と操作説明は[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## リザルト画面

- 表示: スコア、撃破数、正確率、最高連続撃破
- 操作: Enterで復習へ（取りこぼしがなければもう一度）、Escでタイトルへ

終了時に進行を止めることと、終了直後の入力を拾わないことは[ゲームルール](./game-rules.md#ゲーム終了後)を参照。

**間違えた単語の一覧は出さない。** 代わりにEnterで復習へ入り、その場で打ち直させる（[間違えた単語の復習](./review.md)）。読んで終わるより手を動かすほうが覚える。
ハイスコアの保存は[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 復習画面

インゲームの画面をそのまま使い、リザルトを引っ込めて表示を重ねる。**場面が変わっても、打ち込む場所は同じところにある。**

- 画面上部: 見出しと何語目か
- 入力欄の上: いまの段階の指示
- 入力欄の右: ギブアップのボタン。仕上げの段階だけ出す
- 入力欄: 打った文字に続けて、答えやヒントを薄く出す

HUDのスコア・ライフ・経過時間は止めたまま出しておく。

## 文字の表示

TextMeshProを使う。日本語を出すため、日本語のグリフを持つフォントアセットが要る。

いま入っているのは仮のフォント。選定と可読性の最低サイズは[決まっていないこと](./open-questions.md#決まっていないこと)、差し替えは[残っている作業](./open-questions.md#残っている作業)。
