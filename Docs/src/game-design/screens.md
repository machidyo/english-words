# 画面とUI

## 画面構成

| 画面 | 役割 | 遷移先 |
| :--- | :--- | :--- |
| タイトル | 開始 | インゲーム |
| インゲーム | ゲーム本体 | リザルト |
| リザルト | スコア表示、リトライ、タイトルへ戻る | タイトル / インゲーム |

シーンはタイトル用とインゲーム用の2つに分ける。分け方と遷移は[実装構成](./architecture.md)を参照。

**入口となるシーンはREADMEに書く。**

## インゲームのHUD

表示する要素を確定させる。増やしすぎるとタイプ中に読めない。

- 画面上部
  - スコア
  - ライフ
  - 経過時間
- 画面下部
  - 現在の入力中の文字列

## タイトル画面

Enterで開始する。

単語セット・難易度の選択と操作説明は[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## リザルト画面

- 表示: スコア、撃破数、正確率、最高連続撃破
- 操作: Enterでもう一度、Escでタイトルへ

**間違えた単語の一覧は出さない。** 学習用途としてはここが価値の中心になりうるが、記録の仕方から見直しが要る（[スコアと難易度](./scoring.md)、[決まっていないこと](./open-questions.md#決まっていないこと)）。
ハイスコアの保存は[初版のスコープ外](./open-questions.md#初版のスコープ外)。

## 文字の表示

TextMeshProを使う。日本語を出すため、日本語のグリフを持つフォントアセットが要る。

いま入っているのは仮のフォント。選定と可読性の最低サイズは[決まっていないこと](./open-questions.md#決まっていないこと)、差し替えは[残っている作業](./open-questions.md#残っている作業)。
